# robots.txt — annotated template.
#
# Two decisions live in this file and they are commonly confused:
#
#   1. Should search engines index the site?          Almost always yes.
#   2. Should AI companies train on the content?      A business decision.
#
# The trap: for each AI company there are TWO kinds of crawler. The training
# crawler builds the model. The retrieval agent fetches pages to answer a user's
# question right now, and that is where citations and referral traffic come from.
# Blocking GPTBot costs nothing in ChatGPT search visibility. Blocking
# OAI-SearchBot removes you from ChatGPT search entirely. People get this
# backwards constantly.
#
# The default below: allow everything that answers user questions, allow the
# training crawlers too. If you want out of model training, uncomment the
# training block at the bottom.

# ---------------------------------------------------------------------------
# Search engines. Do not block these.
# ---------------------------------------------------------------------------

User-agent: Googlebot
Allow: /

User-agent: Bingbot
Allow: /

# ---------------------------------------------------------------------------
# AI retrieval agents. These fetch pages to answer a question a user just asked.
# Blocking any of them removes you from that assistant's answers.
# ---------------------------------------------------------------------------

User-agent: OAI-SearchBot
Allow: /

User-agent: ChatGPT-User
Allow: /

User-agent: PerplexityBot
Allow: /

User-agent: Claude-User
Allow: /

User-agent: Claude-SearchBot
Allow: /

# ---------------------------------------------------------------------------
# Everything else.
# ---------------------------------------------------------------------------

User-agent: *
Allow: /

# Do not block CSS or JavaScript. Google renders the page; blocking assets makes
# it render broken, and it judges what it rendered.
